# Security Policy

## Сообщить об уязвимости

Пожалуйста, **не создавайте публичный issue**. Используйте GitHub Private Vulnerability Reporting:
вкладка **Security → Report a vulnerability** в этом репозитории.

## Никаких секретов в репозитории

Репозиторий публичный: всё, что попало в коммит, считается раскрытым навсегда (история git).
Запрещено коммитить токены, пароли, ключи, `.env`, дампы БД и персональные данные.

## Что делать при утечке

1. **Немедленно ротировать (отозвать и перевыпустить) ключ/токен/пароль.** Удаление коммита или файла недостаточно — секрет уже в истории, форках и кэшах.
2. Сообщить владельцу репозитория.
3. Только после ротации — при необходимости очистить историю (решение принимает владелец).
