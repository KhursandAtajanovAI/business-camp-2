# src/components/hint

Owner: Dias.

Hints for hard words (EOB, deductible, out-of-network ...).

- `WithHints` — wrap any text in it: glossary words get highlighted and explain themselves on tap.
- `Hint` — one highlighted word with its one-sentence meaning.
- `split-terms.ts` — finds the glossary words in a text (tested).

The words and their meanings live in `src/app/_strings/glossary.ts`.
