# src/app/share

Owner: Dias.

"Share a report" (`/share`). The link carries four numbers and nothing else:
how many things are worth asking about, the money in question, how many papers, the bill health.
No names, addresses, providers, account numbers or lines can be in it (see `share-report.test.ts`).

- `/share` — make a link from the last check.
- `/share?things=3&cents=47050&papers=1&health=76` — what a friend sees.
