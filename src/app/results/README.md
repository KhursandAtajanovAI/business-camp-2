# src/app/results

Owner: Dias.

The results screen (`/results`): the money in question and what we found, in soft words.
It reads the last check saved in the browser by the home or upload screen.

Also here: `LinesEditor` and `LineRow` (correct a line through `src/intake`, the engine counts again), `ReviewCard` with `use-review.ts`
(the live explanation from `src/model-review` with an honest "AI model / locally" badge), `HelperCard` (ask about your papers)
and `CheckBadge` (says whether our rules, the AI model or ordinary code did the thinking).
