# src/app/upload

Owner: Dias.

The upload screen (`/upload`), one calm step at a time:
choose a way (photo, PDF or pasted text) -> we read the paper (`src/intake`) -> see what we understood -> check.
Papers are saved in the browser, so the screen can be left and reopened.
Problems are shown with the kind words that `src/intake` provides, plus a next step.
