# src/letters/letter

Owner: Khursand. The claim letter.

- `letter-content.ts` — fills the template from `content/letters` with the chosen findings.
- `wrap-text.ts` — breaks long text into lines that fit the page.
- `letter-pdf.ts` — draws the letter as a PDF, one letter per billing office.
- `pdf-url.ts` — turns the PDF into a link the browser can download.
