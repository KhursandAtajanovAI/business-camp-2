# src/case-file/store

Owner: Khursand.

- `storage.ts` — where the case is kept (the browser's local storage; memory in tests).
- `case-store.ts` — save, load and clear the case.
- `new-case.ts` — start a case from a check, refresh it when new papers arrive, mark findings as claimed.
- `deadlines.ts` — add a deadline and mark it done.
- `dates.ts` — small date helpers.
