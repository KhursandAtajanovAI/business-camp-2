# docs/deck

Owner: Khursand. The pitch deck: 10 slides, in English, a source under every number.

- `build-deck.mjs` — draws the slides as a PDF. Run `node docs/deck/build-deck.mjs`.
- `deck.pdf` — the result. Rebuild it after every text change.
- `outline.md` — the first draft, kept for history.
