# 0001. Record architecture decisions

- Статус: accepted
- Дата: 2026-11-14

## Контекст

Над проектом работают несколько людей и AI-агентов параллельно. Нужен единый способ фиксировать существенные архитектурные решения.

## Решение

Каждое существенное решение оформляется как ADR в `docs/decisions/` с номером `NNNN-краткое-название.md`: контекст, решение, последствия. Принятые ADR не переписываются — заменяются новым ADR.

## Последствия

Решения прозрачны и находятся рядом с кодом; новые участники быстро восстанавливают контекст.
